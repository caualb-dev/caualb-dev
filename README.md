## 👨‍💻 Sobre Mim

Olá! Sou graduando em **Ciência da Computação pelo IFCE (Instituto Federal do Ceará)** e desenvolvedor com foco prioritário em **engenharia de software backend** no ecossistema **Java & Spring Boot**.

Minha atuação é voltada para a construção de **APIs RESTful seguras, resilientes e escaláveis**, unindo boas práticas de modelagem de dados relacionais, tratamento defensivo de erros e desacoplamento arquitetural. Também possuo experiência prática na integração de serviços com ecossistemas modernos de frontend em **React & TypeScript**.

- 🔭 **Foco atual:** Arquitetura de microsserviços e monolitos modulares com Spring Boot 3, Spring Security (JWT) e Docker.
- 🎓 **Formação:** Bacharelado em Ciência da Computação — IFCE (Campus Fortaleza).
- 💡 **Interesses:** Princípios SOLID, Clean Architecture, Testes Automatizados (JUnit 5 / Mockito), Otimização de Queries SQL e CI/CD.

## 📐 Padrões & Práticas de Engenharia

- **SOLID & Clean Architecture:** Código modularizado com regras de negócio concentradas em services e DTOs imutáveis.
- **Defensive API Design:** Validação de payload via Bean Validation (`@Valid`, anotações Jakarta) e padronização de erros HTTP.
- **Versionamento & Git Flow:** Adoção rigorosa de *Conventional Commits* (`feat:`, `fix:`, `refactor:`, `docs:`).
